# Profile STEP Files

Place profile STEP files here for the solid service to use:

- `1108038_profil_a8_40x40_leicht.step` - 40x40 profile (for frameWidth ≤ 500mm)
- `1108055_profil_a8_80x40_leicht.step` - 80x40 profile (for frameWidth > 500mm)

These files are automatically imported and scaled to the conveyor length when generating STEP exports. If profiles are not available, the service falls back to box-based frame geometry.
